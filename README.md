# Bave Digital Invitations

Template maître réutilisable d'invitation de mariage digitale interactive — projet BAVE PICTURES (direction artistique Ivory & Gold).

## Contenu

- `index.html` — la page d'invitation (actuellement l'exemple "Yves & Clarisse")
- `img/` — photos du couple et éléments graphiques (sceau de cire)
- `audio/` — musique de fond
